# Decision: Cheirismos name

**Status:** accepted

The project is named **Cheirismos** (χειρισμός), “handling” or “manipulation.”
The sense fits a governed system for deliberate physical interaction with a
device under test. The Lexicon of Liddell, Scott, and Jones records the noun at
`grc.lsj.perseus-eng25.xml` entry `n113595`.

The short prefix `ch` is available for the project. It is not a claim that all
future packages must use the prefix; names should continue to state their own
role.
